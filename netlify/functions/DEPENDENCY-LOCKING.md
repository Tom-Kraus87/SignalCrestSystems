# Netlify Functions dependency locking (M7A-R4 / R3-08 / R6-A)

## Effective deployment package

Netlify resolves Functions dependencies from `netlify/functions/package.json`
(see root `netlify.toml` `functions = "netlify/functions"`). The public site
build (`scripts/build-public.mjs`) does **not** install or bundle these
server-only packages into `dist/`.

## Effective Netlify build command (M7A-R6)

Root `netlify.toml`:

```toml
command = "npm ci --prefix netlify/functions && node scripts/build-public.mjs"
```

| Step | Purpose |
|------|---------|
| `npm ci --prefix netlify/functions` | Clean install from committed `package-lock.json` (exact `pg@8.13.1`). |
| `node scripts/build-public.mjs` | Public artifact allowlist build into `dist/` (unchanged). |

Local agents must **not** execute `npm ci` / `npm install` without separate Owner authorization.
Static compatibility: `package-lock.json` present, lockfileVersion ≥ 2, `pg@8.13.1` integrity under `registry.npmjs.org`.
