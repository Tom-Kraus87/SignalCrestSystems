## Binding Phase A (ship-first)

1. Official deterministic product: **Guided Solutions Advisor** / public label **AI Solutions Advisor**  
2. **Not a language model** in Phase A — chips + rules + knowledge pack only  
3. ≤6 qualification steps; **PRIMARY follows `project_type`** (R3.1 matrix T01–T23)  
4. Every PRIMARY maps to an approved contact/project-request `service` value  
5. Pricing only from `packages.html` — no invented prices or guarantees  
6. Editable project brief from chip answers + user text  
7. Consent unchecked by default; Send **visibly disabled** until checked  
8. Approved consent wording + Privacy Policy link  
9. Talk to a human always available  
10. Handoff into existing form workflow with `source=advisor` only via safe handoff flag; direct visits keep `source=contact`  
11. Static `privacy-version` stamp  
12. CSP-safe; no browser LLM keys; no new third-party scripts  
13. Themes + a11y + mobile support  

## Adaptive Technical Support (credit rules — Phase A deterministic UX; live LLM = Phase B)

1. Two entry modes: **Help Me Fix Something** / **Find a Business Solution** (+ human)  
2. Three free substantive troubleshooting topics per session  
3. Same-issue follow-ups do **not** consume credits  
4. Soft-cap: no hard cut mid-issue; block fourth new topic; offer summary + professional route  
5. Never request passwords / MFA / recovery keys  
6. Confirm before disruptive suggestions; never execute on customer device  
7. Escalate to `it-consulting` (or cyber/care/other when indicated)  
8. Live LLM endpoint requires **separate approval** (not implemented this round)
